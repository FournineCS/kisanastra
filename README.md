# Kisan Astra — Legal & Support Site

Static site hosting the **Privacy Policy** and **Support / FAQ** pages for the
[Kisan Astra](https://apps.apple.com/) smart agricultural pump controller app,
published by Fournine Cloud Solutions Private Limited.

Served via GitHub Pages:

| Page    | URL                                            |
| ------- | ---------------------------------------------- |
| Home    | https://fourninecs.github.io/kisanastra/         |
| Privacy | https://fourninecs.github.io/kisanastra/privacy.html |
| Support | https://fourninecs.github.io/kisanastra/support.html |

These URLs are referenced in App Store Connect (Privacy Policy URL and Support
URL) and Google Play.

## Editing

Plain HTML + one stylesheet — no build step. Edit the `.html` files and
`style.css`, commit to `main`, and GitHub Pages redeploys automatically.

```
index.html     Landing hub
privacy.html   Privacy Policy
support.html   Support & FAQ
style.css      Shared styles
icon.png       App icon
```
